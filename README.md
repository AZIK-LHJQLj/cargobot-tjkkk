# Cargo Line TJ — простой Telegram-бот (без мини-аппа)

Два бота в одном файле:
- **@CargoLineTJ_Bot** — для клиентов (поиск трека, адрес, калькулятор…)
- **@CargooLine_bot** — админка (массовая загрузка треков до 3000)

## Что умеет

- Массово добавить до **3000** трек-кодов за раз (текст или файл `.txt`)
- Статусы: **В Китае** → **В пути** → **На складе в Худжанде**
- Сохраняется **дата и время** каждого статуса
- Через **3 дня** треки «В Китае» сами переходят в «В пути»
- Клиент видит текущий статус и даты по всем этапам

## Как залить на Railway (бесплатно)

1. Создай репозиторий на GitHub
2. Перетащи **всю эту папку** в репозиторий (или `git push`)
3. На [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub**
4. Выбери этот репозиторий
5. Railway сам запустит `python bot.py` по файлу `Procfile`

Готово — боты работают 24/7.

## Локальный запуск (по желанию)

```bash
pip install -r requirements.txt
python bot.py
```

## Админка — как грузить 3000 треков

1. Открой **@CargooLine_bot**
2. Выбери статус (Китай / В пути / Худжанд)
3. Пришли список текстом **или** файл `.txt` (каждый код с новой строки)

Можно сразу грузить в «В пути», не только в «Китай».
